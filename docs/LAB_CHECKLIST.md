# Lab Checklist

## Before exercise
- [ ] Scope is your own lab / explicitly authorized.
- [ ] VM snapshots taken.
- [ ] Network isolation verified (no bridged/NAT where required).
- [ ] Host shared folders/clipboard reviewed.
- [ ] Logging enabled (Sysmon/Defender/Event logs).

## During exercise
- [ ] Work on sample copies only.
- [ ] Static analysis before any execution.
- [ ] Record hashes, timestamps, commands, observations.
- [ ] Capture relevant events/screenshots.

## After exercise
- [ ] Revert snapshots if needed.
- [ ] Store report in `reports/` (no sensitive data leaks).
- [ ] Do not publish live samples.
- [ ] Update detection rules/notes with lessons learned.
